# 🕹️ Hangman Game (Python)

📌 About:
A simple game built using Python.
This project helped me understand basic 
programming concepts like loops, functions,
and user input handling.

🎯 Features:
* Random word selection
* Letter-by-letter guessing
* Input validation
* Hangman visual display
* Win/Loss conditions

▶️ Run the Project:
To run the project copy this code to any code editor and then run the command hangman.py(File name - hangman)

🧠 Concepts Learned:
* Functions & modular coding
* Loops and conditionals
* Lists & sets
* Basic game logic


🚀 Conclusion:
This is a beginner-friendly project that strengthened my **core Python fundamentals** and improved my problem-solving skills.
